**Result:** pass with shared-network and provider-accounting caveats.

A deliberately small single-stream transfer workload was executed on the real Appbox through the trusted GitHub Actions SSH lane. The canonical successful run was Actions run `34788373781` from remote execution commit `550a204ebecca9d9bbc99cf64d506e5ebd2d64d8`, starting at 2026-09-13T22:59:43Z and finishing at 22:59:47Z.

## Workload

The committed `tools/qualify_network.sh` defaults were used after endpoint qualification:

- 3 × 64 MiB inbound HTTPS transfers;
- 3 × 32 MiB outbound HTTPS POST transfers;
- one unmeasured 64 KiB TLS warm-up;
- one stream at a time;
- no response data retained locally;
- temporary upload body removed before exit;
- hard script guardrail limiting planned outbound traffic to 512 MiB per invocation.

Canonical measured traffic was therefore 192 MiB inbound and 96 MiB outbound, far below the programme's 50 GB qualification ceiling.

The first live attempt requested 128 MiB per Cloudflare generated download and received HTTP 403 after the small warm-up succeeded. That attempt stopped immediately before meaningful measured traffic. The reusable tool was then constrained to 16–96 MiB per request and the canonical 64 MiB pass succeeded. This is endpoint policy behaviour, not an Appbox network failure.

## Provider context and accounting

Bytesized's current documentation says Appbox network capacity is shared and advertises a 10 Gbit connection for the current Lite plan. The measured single-stream rates above are therefore practical path observations, **not** evidence that this tenant owns or can continuously consume a dedicated 10 Gbit link.

Current Bytesized documentation also states that traffic uploaded/generated by the Appbox counts against the monthly upload allowance while downloads to the Appbox are unlimited. The provider's account bandwidth counter was not exposed through the available SSH execution surface, so before/after panel-counter validation was not practical in this run. Evidence therefore records exact generated payload byte counts and does not invent a counter delta.
